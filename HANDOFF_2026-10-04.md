## Gotchas & Warnings

1. **CNAME file is critical** — if removed, Pages falls back to .github.io and DNS check stalls. Always verify it exists before assuming a deeper problem.
2. **LF vs CRLF warnings on commit** — normal on Windows; doesn't break anything.
3. **Media file renames** — if you rename/move any .jpg/.webp/.mp4, update every HTML reference or pages will 404 those assets.
4. **Redirect stubs** — `/our-menus`, `/about`, `/contact`, `/locations` folders exist to handle old Squarespace sitelinks (use meta-refresh + canonical redirects). Don't delete them.
5. **No native server redirects** — GitHub Pages has no server-side redirect config; use HTML meta-refresh for legacy URL mapping.
